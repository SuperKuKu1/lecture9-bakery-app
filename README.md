# Lecture 9 Bakery App

An order tracking app for a home baker who takes cupcake and cake orders by Instagram DM (MGOC50, Lecture 9).

- `Bakery-Tracker.html`: the app built from the class wireframe and state diagram.
- `Bakery_Tracker_F.html`: an improved version with the same rules. It has a week strip, one message list, and advice on when a $100 helper pays off.
- `README.html`: how to use the app, the rules, the state diagram, the actions, and the test results.

To use it, download a file and open it in a browser. No install or server is needed.
